使う側へ。

応用数学研究部(応数研・OSK)は、東京理科大学のⅠ部研究会に属する部活動です。1959年の創部から半世紀以上続き、数学を「使う」ことをテーマに、機械学習・データサイエンス・統計学・競技プログラミング・コンピュータサイエンス・3DCG・Web/アプリ開発に取り組んでいます。部員は数学科・応用数学科の学生が多いですが、他学科・他学部の部員もいます。

応数研とは班とプロジェクト

Basics

はじめての方へ

どんな部？
数学・プログラミング・データサイエンス・統計・AI に取り組む、東京理科大学の部活(サークル)です。
活動日
班ごとに週1回集まります。機械学習班は水曜18:00〜、数理統計班は金曜16:15〜、コンピュータサイエンス班は日曜20:00〜、競技プログラミング班は土曜22:50〜です。時間が合わなくても Discord でいつでも参加できます。
場所
神楽坂キャンパス 2号館5階 2507教室(部室)。勉強会の多くは Discord でオンラインでも参加できます。
部費
前期・後期それぞれ 2,000円です。
未経験
歓迎です。毎年5〜6月に、プログラミング未経験の新入生向け講義(C++、全3〜4回)を開いています。
学部・学科
数学科・応用数学科の学生が多いですが、他学科・他学部の部員もいます。
新しい活動
班にない分野でも、部員を集めて勉強会やプロジェクトを立ち上げられます。
兼部・見学
兼部できます。見学は Discord サーバーへの参加で、いつでもできます。

Teams

班とプロジェクト

興味に合わせて班を選びます。いくつ掛け持ちしても、新しく立ち上げても構いません。

  • 機械学習班

    AI・機械学習・データサイエンスを、本の輪読と手を動かす実装で学びます。

    毎週水曜 18:00〜

  • 競技プログラミング班

    AtCoder や ICPC(大学対抗プログラミングコンテスト)に挑み、アルゴリズムの腕を磨きます。

    毎週土曜 22:50〜(コンテスト後の感想戦、オンライン)

  • 数理統計班

    統計学・多変量解析・因果推論を、統計検定準1級を目標に学びます。

    毎週金曜 16:15〜(神楽坂キャンパスの教室)

  • コンピュータサイエンス班

    型理論・自作言語・定理証明(Lean)・OS など、計算機科学の理論をゼミ形式で深めます。

    毎週日曜 20:00〜(オンライン)

  • 3DCG

    Blender でのモデリングや、Unity でのゲーム・VR 制作に取り組みます。

    プロジェクト型で活動

  • Web・アプリ開発

    Web アプリをチームで作ります。GitHub での共同開発やハッカソンへの参加も。

    プロジェクト型で活動

In numbers

数字で見る応数研

  • 1959年

    創部。東京理科大学の応用数学科よりも早く生まれた部です

  • 6つ

    班とプロジェクト。やりたいことがなければ、自分で立ち上げられます

  • 2,000円

Every year

1年の流れ

  1. 4月

    新歓

    班紹介や部室でのボードゲーム会など。見学は Discord からいつでもできます。

  2. 5月

    新入生講義・班の活動開始

    プログラミング未経験の新入生向けに、C++ で AtCoder の問題を解けるところまでを全3〜4回で教えます。

  3. 7月

    ICPC 国内予選

    国際大学対抗プログラミングコンテスト。3人1組のチームで出場します(2026年度は6チーム)。

  4. 11月

    理大祭

    コーヒーを出すカフェ「Hackers' Cafe」と、各班の作品展示を行います。

  5. 3月

    春季合宿(予定)

    班を越えて集まり、勉強会や企画を行います。
