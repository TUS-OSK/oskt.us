## 0. 方針

### 0.1 届けたい検索

部の名前（応用数学研究部・応数研・OSK）を知らない人が、もっと広いカテゴリで調べたときに例として挙がることを狙う。

| 系統 | 想定される調べ方 |
|---|---|
| プログラミング | 理科大 プログラミング サークル／競技プログラミング サークル／ICPC 理科大 |
| 数学 | 理科大 数学 サークル／数学系サークル／応用数学 部活 |
| データ・AI | データサイエンス サークル／統計 サークル／統計検定 勉強会／AI サークル／機械学習 サークル |
| CS | コンピュータサイエンス 勉強会／Lean 定理証明／型理論 自作言語 |
| 文系・経営 | ビジネスエコノミクス サークル／経営学部 データ分析 サークル／計量経済 勉強会 |

検索エンジンも AI 検索も、本文に書かれた言葉と事実を拾う。キーワードを並べるのではなく、上の言葉が「何をしているか」の説明として自然に入る文にする。

### 0.2 書き方のルール

- **カテゴリ語を名前の近くに置く。** 「東京理科大学の〜サークル」の形で、大学名とカテゴリを同じ文に入れる。
- **「部」と「サークル」を両方書く。** 正式には部活動（Ⅰ部研究会）だが、探す側は「サークル」で調べる。
- **事実は一文で言い切る。** 曜日・場所・金額・人数は、AI がそのまま引用できる短い文にする。
- **トーン:** 落ち着いた丁寧語。トップのボタン（部の様子／ご連絡）のように、少し和の癖を入れるのは見出しやボタンまでにとどめる。本文は検索に拾われやすい平易な文にする。
- **個人を出さない。** 部員の名前・ハンドルは書かない。学科構成は粗い区分で書く（1名の学科は出さない）。

### 0.3 根拠にした情報

- サイトの既存の文面（about.md・faq.md・contact.md）
- 部員の学部・学科構成の集計（秘書ちゃんレポート、2026-11、登録38名＋未登録8名）
- Discord の全員向けチャンネルの投稿（2023-04〜2026-11）。役員・個人情報・鍵付きのチャンネルは除外した。

## 3. About（応数研とは）

### 3.1 冒頭の説明（about.md の `caption`）

今の文は「コンピュータを利用してプログラミングを主に」で、数学・統計・AI が出てこない。差し替え案:

> 応用数学研究部(応数研・OSK)は、東京理科大学のⅠ部研究会に属する部活動です。1959年の創部から半世紀以上続き、数学を「使う」ことをテーマに、機械学習・データサイエンス・統計学・競技プログラミング・コンピュータサイエンス・3DCG・Web/アプリ開発に取り組んでいます。部員は数学科・応用数学科を中心に、他学科・他学部からも集まっています。

### 3.2 班について（about.md の箇条書きを差し替え）

各班に「何をするか／いつ・どこで／こんな人に」の3行。詳しくは 4章の班ページに送る。

- **機械学習班** — 機械学習・データサイエンス・統計モデリング(回帰分析など)を、輪読と実装で学びます。Kaggle のコンペやロボットシミュレーション(NVIDIA Isaac Sim)にも取り組みます。毎週水曜 18:00〜。
- **数理統計班**(2026年度開設) — 統計検定準1級の取得を目標に、多変量解析・統計的推測・因果推論を輪講形式で学びます。毎週金曜 16:15〜、神楽坂キャンパスの教室で。
- **競技プログラミング班** — 毎週土曜の AtCoder Beginner Contest に参加し、終了後の 22:50 から感想戦をします。ICPC(国際大学対抗プログラミングコンテスト)にはチームで出場し、コーチ・監督も部で用意します。
- **コンピュータサイエンス班**(旧・低レイヤ班) — 型理論、ラムダ計算、自作プログラミング言語、定理証明支援系 Lean、OS、論理学などを、ゼミ形式で「ゆるく深く」学びます。毎週日曜 20:00〜、オンラインで。
- **3DCG班・Web・アプリ開発班** — 【未定】今年度の形が決まるまで、次のどちらかにする。
  - 動いている場合: 4.5 の素材で通常の班として書く
  - 決まらない場合: 下の「プロジェクト」の例として挙げるにとどめる(「CG や Web アプリを作りたい人が集まってプロジェクトを立ち上げています」)。動いていない班を「班」として載せると、それ目当ての新入生をがっかりさせる(CS班の新歓の議論でも指摘あり)

班の時間に合わなくても大丈夫です。勉強会は Discord に記録が残り、いつでも質問できます。

2. **学部・学科の広がり:** 「数学科だけじゃない」が伝わる粒度(数学系／理学部の他学科／工学・情報系／経営学部)。1名の学科は出さない
3. **経験の有無:** 「入部時プログラミング未経験だった人の割合」。これは名簿にないので、新歓前に部員アンケートで取ると強い

> 数学科・応用数学科の学生が多いですが、化学・物理・情報系や経営学部の部員もいます。プログラミング未経験で入部する人も毎年います。

- 学科構成と人数は名簿データを広報に使う形になる。データ管理規則 第5条の「勧誘・広告等に転用しない」に触れないよう、幹部の合意を取ってから出す(未了)
- 他大学の部員は書かない。学外生の建物への出入りについて学生支援課との手続きが整うまでは、大々的に出さない。FAQ の既存の「他大の者でも入部可能」は変えずに残し、トップや数字のタイルには載せない

## 5. FAQ

### 5.1 足す質問

- **理学部以外・経営学部でも入れますか？**
  > はい。部員は数学科・応用数学科が中心ですが、経営学部ビジネスエコノミクス学科や、化学・物理・情報系の学科の部員もいます。統計やデータ分析に興味がある人には、数理統計班や機械学習班がおすすめです。
- **データサイエンスや統計を学べますか？**
  > 数理統計班が統計検定準1級を目標に統計学を、機械学習班が機械学習・データ分析を扱っています。
- **AI(機械学習)を学べますか？**
  > 機械学習班で、輪読と実装を通じて学べます。
- **数学が得意でなくても大丈夫ですか？**
  > 大丈夫です。数学を「使う」ことが目的の班が多く、必要な数学はその都度一緒に学びます。
- **ICPC に出られますか？**
  > はい。毎年チームを組んで出場しています。コーチ・監督員は部で用意し、練習会も開いています。
- **活動日・場所はどこですか？**
  > 班ごとに週1回集まります。機械学習班は水曜18:00〜、数理統計班は金曜16:15〜、コンピュータサイエンス班は日曜20:00〜(オンライン)、競技プログラミング班は土曜22:50〜(AtCoder のコンテスト後の感想戦)です。部室は神楽坂キャンパス 2号館5階 2507教室です。
- **授業やバイトで班の時間に出られません。**
  > 大丈夫です。勉強会の内容は Discord に残るので、自分のペースで追いつけます。質問もいつでもできます。
- **やりたい分野の班がありません。**
  > 部員を集めて、新しい勉強会やプロジェクトを立ち上げられます。
