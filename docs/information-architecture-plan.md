# oskt.us 情報アーキテクチャ計画（検討中・未着手）

> このドキュメントは実装計画ではなく、構想を書き溜めるためのメモ。
> 合意が取れた部分から随時実装に落とす。矛盾・変更があれば都度この文書を更新する。

## 背景・目的

Discord経由でmarkdownコンテンツを編集できる基盤（`site-edit`機能、OSK-hisyochanリポジトリ側）ができたことで、役員が高品質に・楽に更新できる環境自体は整った。ただしそれは「既存の構造の中身」を埋めやすくするものであって、構造自体がスケーラブルでなければ、結局「想定されていない構造改変」が繰り返し必要になる。

このドキュメントの目的は、そうした場当たり的な拡張が今後不要になるよう、最初から拡張性のある情報設計（IA）を検討すること。

## 現状の構造監査（2026-09-04 実施、確定事項）

- ページ構成: `/about` `/schedule` `/news`＋記事群(`_articles/markdowns/<年>/<slug>`) `/archive` `/contact` `/faq` `/pay` `/ridaisai/2021` `/ridaisai/2023`
- **良い部分**: About/FAQ/Schedule/記事はすべてMarkdown駆動で統一され、記事は年次コレクション構造でスケーラブル
- **問題点**:
  1. `/pay`（入部）がヘッダーメインナビ（`src/components/Menu`）に無い。トップページのフローティングバナー1箇所のみが導線
  2. `/ridaisai/2021`・`/ridaisai/2023`はサイト内のどこからもリンクされていない孤立ページ。理大祭のたびに専用ミニサイトを一から作るパターンで、2022・2024・2025年度分は存在せず運用が続いていない
  3. `/archive`（サイトマップ的ページ）が手書きMarkdownでメンテ漏れ（2023年度セクションが空、多くの記事年度が未掲載）
  4. 班（Web班・CG班・競プロ班等）を紹介する専用の場所が無い。Aboutに簡単な説明があるのみ

## 検討中のコンセプト

### 1. 「特集」（Feature Series）— 定期開催イベント専用のコンテンツ種別

不定期の単発ニュース（`_articles`）とは分離する。理大祭・ICPC等、**毎年（毎回）開催されるもの**を対象とする。

- 親: 特集一覧ページ（例: `/features`）— 「理大祭特集」「ICPC特集」等のシリーズを並べる
- 子: 各シリーズページ内に年度ごとのエントリ（現状の`/ridaisai/2021`のような孤立ページを、ここに統合するイメージ）
- **表示方針**: newsのようにフラットに並べるのではなく、直近・最新のものを大きく強調表示し、過年度分は控えめに・区別して後方に配置する（並置しない）。理由: 見たいのは基本的に最新であり、過去分は「一覧できればよい」程度の位置づけのため

未確定:
- 過年度分の見せ方の具体（何件まで見せる／折りたたみ／年度セレクタ等）
- シリーズの新規追加は誰が判断するか、Discord編集の範囲内で完結できるか、コード変更が要るか
- データ構造（例: `_features/markdowns/<series-slug>/<year>.md` + front matterで`series`/`featured`等を持たせる案）

### 2. 班紹介ページ — 「特集」とは別の基本情報カテゴリ

ニュース・特集のような時系列コンテンツではなく、Aboutに近い静的な基本情報として別に作る。

未確定:
- データ構造（班の追加・削除がコード変更無しでできるよう、構造化データ＝JSON/YAML等で持つ案）
- 各班のページ単位か、一覧ページ内でのセクション単位か

### 3. サイトマップ自動生成

合意済み。`/archive`の手書き運用をやめ、実際のページ・記事・特集一覧から自動生成する方式に変える。
